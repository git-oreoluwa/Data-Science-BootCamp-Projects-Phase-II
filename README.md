## 🚀 Projects

### 📊 Uber Travel Analysis (EDA & Visualization)
**Domain:** Urban Transportation / Logistics
* **Objective:** Analyze user travel patterns to optimize resource allocation and understand peak demand.
* **Key Insights:**
  * Identified peak travel hours and busiest months for ride requests.
  * Analyzed trip purposes (Business vs. Personal) and average distances covered.
  * Mapped the most frequent starting locations to identify high-demand zones.
* **Tech Stack:** Python, Pandas, Matplotlib, Seaborn.
